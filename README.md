# WhatsApp Sales Accelerator

Micro-SaaS CRM desarrollado para optimizar la gestión de ventas y la comunicación rápida a través de WhatsApp. Cuenta con una interfaz flotante intuitiva, administración local de contactos y herramientas ágiles de mensajería.

## 🚀 Tecnologías
* Node.js & Express
* Interfaz y gestión local optimizada para dispositivos móviles y web.

## 💡 Descripción
Creado para resolver problemas reales de negocio de punta a punta, permitiendo un flujo de trabajo rápido, ligero y sin rodeos.
